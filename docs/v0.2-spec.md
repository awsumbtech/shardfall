# Shardfall v0.2 shared spec ("Act 1: The Cinder Road")
Three cloud agents are working in parallel on separate PRs off main. Stay inside your lane, and follow the contracts below so the PRs merge cleanly.

## Content (canonical; all agents use these names and ids)
- Islands: Emberhold (exists), Cinderveil (NEW: ash-grey and ember-orange island with a dormant shard core, a Driftborn harbor town called Lowmoor Quay, the Ashfields, and the Ember Vault). Travel between them on Kestrel's skiff.
- Cinderveil NPCs: Kestrel Vane (sailing and travel), Tamsin Reed (young Driftborn tinkerer; she fits the Grapple into the Wayfarer's hand), Brother Hesk (nervous Hollow Choir defector who has info about the Cantor), Warden Ilsa (stern Lanternwright guarding the Ember Vault).
- Cinderveil quest chain: (1) arrive at Lowmoor Quay; (2) help Tamsin gather 3 cogs in the Ashfields, which unlocks the Grapple; (3) grapple across to the Ember Vault, past Ilsa's trial; (4) boss fight with the Cinder Maw, a Hushborn that's been feeding on the core; (5) relight the Cinderveil lamp; (6) the Cantor appears with a choice: Spare, Listen, or Refuse. Set flag cantor_choice = spare|listen|refuse. This is the hook for Act 2.
- The Emberhold NPCs Old Maren and Kestrel get rewritten dialogue too.

## Dialogue contract
- Content lives in js/content/dialogue/*.js as plain data. Node ids are dot-separated: `emberhold.maren.intro`, `cinderveil.tamsin.cogs_start`, etc.
- Node shape: { id, speaker, portrait?, lines: [string], choices?: [{ text, next?, setFlags?, requires? }], next?, onEnd?: "event_name" }
- Gameplay code starts a conversation with `startDialogue(id)` and reacts to the `onEnd` events, using flags stored in the save (`state.flags`).
- Required node ids and events (the WORLD agent calls these; the STORY agent writes them):
  - emberhold.maren.intro / emberhold.maren.waiting / emberhold.maren.lamp_lit (onEnd: quest_lamp_done)
  - emberhold.kestrel.offer_sail (onEnd: open_sail_menu)
  - cinderveil.kestrel.arrive
  - cinderveil.tamsin.cogs_start (onEnd: quest_cogs_start) / cinderveil.tamsin.cogs_waiting / cinderveil.tamsin.grapple_gift (onEnd: grant_grapple)
  - cinderveil.hesk.rumor
  - cinderveil.ilsa.trial (onEnd: vault_open)
  - cinderveil.maw.prefight (onEnd: boss_start) / cinderveil.maw.defeated
  - cinderveil.lamp.relit (onEnd: quest_cinder_lamp_done)
  - cinderveil.cantor.confront (choices set cantor_choice; onEnd: act1_end)
  - inspect.<thing> nodes for interactable signs and objects
- Any id the WORLD agent needs that isn't written yet should fall back gracefully to a one-line placeholder. It must never crash.
